# Dinastia Piscinas — Prévia Consecom

Site demonstrativo com construção, reforma, iluminação, revestimentos e planejador interativo.

Abra `index.html` no navegador. As sete imagens em `assets/*.webp` foram ampliadas e restauradas a partir de capturas do Instagram, preservando texto e composição. Não foram inventadas fotos ou informações da empresa.

O planejador é ilustrativo e não representa projeto técnico ou orçamento. O visitante copia o resumo e abre o WhatsApp oficial para solicitar informações.

A foto de abertura utiliza fotografia ilustrativa remota; a fonte usa Google Fonts. Se estiver offline, o site oferece fallback de fonte e imagem local. Proposta não oficial sujeita a aprovação.
