# Consecom Preview

Vitrine estática de sites criada e mantida via ChatGPT/GitHub.

## Uso

Hospede o repositório na Vercel como **Other / Static**, sem build command e com diretório de saída `.`. Os cards são lidos de `projects.json`; cada site completo fica em `sites/<slug>/`. Veja `AGENTS.md` para o padrão obrigatório de qualidade.
